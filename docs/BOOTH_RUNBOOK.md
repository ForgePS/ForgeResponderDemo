# Forge Responder Trade-Show Runbook

## Before opening the booth
1. Connect the booth laptop/tablet to power.
2. Confirm the browser is current.
3. Start the Forge Responder demo build.
4. Open `/en/demo-readiness`.
5. Confirm Mapbox is configured if GIS will be demonstrated.
6. Open `/en/demo-control` and reset local demo actions.
7. Open `/en/guided-demo`.
8. Enter browser full-screen mode.

## During demonstrations
- Use Guided Demo for the standard 10-step sequence.
- Use Demo Control for direct workflow launches.
- Use the floating toolbar to reset local demo actions.
- Source-backed data is read-only.
- NERIS/NEMSIS external submissions are disabled.

## Between attendees
1. Press **Reset** on the booth toolbar.
2. Return to Guided Demo step 1.
3. Verify full-screen mode is still active.
